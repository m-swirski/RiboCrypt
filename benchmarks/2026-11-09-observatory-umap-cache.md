# Observatory UMAP precomputation

Human collection: 4,522 RFP libraries, existing 2D projection, tissue and cell-line colors; R 4.5.3, local server, Chromium headless, one BLAS thread. The default object contains 177 grouped Plotly traces. The selection onRender hook is attached after loading the cached object. Five R-level trials in a fresh process produced median elapsed time **0.087 s** to read the FST and build the templated Plotly object versus **0.010 s** to read the uncompressed cached object and verify the FST MD5. Data and layout were compared exactly. This measures R object preparation, not browser rendering.

The end-to-end test opened a new browser page directly at `#Observatory` and waited for the 4,522-point Plotly widget to have a full layout. With caching disabled the three new-session times were 8.254, 3.937 and 3.361 s; with caching enabled they were 7.843, 3.903 and 3.151 s. Modes were run sequentially rather than randomized, and the Shiny app and OS caches warm between sessions; these are exploratory timings, not a reliable causal estimate. They show that the serialized plot saves only a small part of total page latency. Browser rendering, initialization and other Observatory work remain material. Merely converting another R function to C++ would not address those costs.

The cached plot is used only for public, unfiltered sessions with tissue + cell-line colors and axes 1/2 in the original 2D embedding. The input FST MD5, exact collection Run order and Plotly version must match. A missing, stale, unreadable or incompatible cache falls back to the original FST-to-Plotly construction. Access-filtered sessions always use the filtered table. The 6D projection is separate; it is computed independently and its axes must not be interpreted as additional axes of the old 2D embedding. Selection synchronization is attached per session after cache loading.

Raw measurements and reproducible scripts: `~/shared_workspace/hakon_playground/observatory_umap_20261109/benchmark_default.R`, `benchmark_browser.py`, `browser_timings.csv`. Cache build: `inst/scripts/precompute_observatory_umaps.R`.
